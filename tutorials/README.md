# Future of Learning workshop tutorials

**Stop Waiting for the Perfect App: Vibe Code It Together**
Building private classroom tools with AI that works where you teach

https://dbbudd.github.io/Lineage/tutorials/

The first page is a text-led workshop flow, aligned with the presentation in
`../workshop/`. It follows the warm-ups, barrier, Automate demonstration, sketch,
prompt spine, WebApp build/test, SCAMPER, Agents and continued iteration.

Stage pills use the presentation labels and colours: Automate (navy), WebApp
(slate) and Agents (red). Tool names are separate. Flint, ChatGPT, Claude chat/Artifacts
and Claude Code are optional guides under More to explore. GitHub Pages, Vercel
and App Store remain publishing references.

The Xcode guide is an orientation and configured-agent test. Detailed Xcode provider
setup and a separate Copilot guide remain to be written.
DeepSeek Harness is now a main Build 02 Agents guide, with six sections covering
setup, local files, a small build, testing, skills and a repeatable workflow.
The downloadable **A3 handout** now follows the same eleven-step flow and timings.
Its reverse covers Automate (Apple Shortcuts), WebApp (Gemini) and Agents (Xcode,
Copilot and DeepSeek), with clickable guide links and a tutorials QR code. Print
the two A3 portrait pages double-sided at actual size. The legacy October download
URL serves the same updated PDF, preserving existing bookmarks. The editable HTML
and build scripts remain in the HyperFrames project’s `handout` folder, with the
October version archived outside this repository. ChatGPT is restored as an
optional extra, with its original 3 October test date, screenshots and a regional
availability note. The two Claude guides use official documentation checked on
6 November 2026, locally stored official imagery with linked captions, and original
classroom practice prompts. The main workshop flow is unchanged.

This is a static folder of the parent Lineage repository. Do not initialise a
second Git repository here. Navigation, glossary and tracked counts are defined
in `assets/toc.js`. Shared reading tools live in `assets/course.js`;
`assets/flow.css` and `assets/flow.js` style the text-led homepage. Assets use
version 7 after this revision. Theme, font size, dyslexic font, Focus, Listen,
Translate, search and completion controls remain available.

The original magazine homepage, previous guides and the copied independent Git
history are archived outside the Lineage repository in the HyperFrames project.
