# Official Claude tutorial imagery

`official-chat-prompt.png` is the prompt-box screenshot from Claude Help Center’s
Get started with Claude. `official-code-review.png` is Anthropic’s review-interface
illustration from Preview, review, and merge with Claude Code.

Images are stored locally, with their original aspect ratios and linked credits
in the tutorial figure captions. They show example interfaces, not results from
the classroom practice prompts. Original artwork remains attributed to Anthropic.
See `official-sources.json` for original URLs, retrieval date, dimensions and hashes.
The older `download.jpg` is historical material from the earlier project.
